# RESEARCH.md

## Topic: Entry Quality / Market D As Buy Blocker

## Conclusion

Common breakout/retest practice supports checking:

- break/retest confirmation;
- volume confirmation;
- risk-reward before entry;
- avoid chasing limit-up / overheated moves;
- distinguish setup quality from execution timing.

However, `market_grade D` or `entry_quality D` should not be the first visible blocker when a more specific blocker exists. It is better treated as background strength or setup-quality detail.

## Applied Rule

- If the stock is overextended or limit-up, show cooldown/retest first.
- If it is a strong rebound, show retest first.
- If RR is below threshold, show risk-reward first.
- If it is far from trigger and no better setup exists, show approach/distance first.
- Show quality D as a detail only when the issue is genuinely setup quality.
