## Owner Problem

The 06/23 report still reads inconsistent from a mobile user perspective:

- 2026-06-23 is a trading Tuesday, but one run was labeled `非交易`.
- Cards showed overheat pullback as `等回測`, while summary still counted them as `等冷卻`.
- Pullback / sharp pullback triggers were too generic.
- `淘汰｜觀察` did not explain a real rejection reason.
- Breakout failure cards could still show positive volume wording like `攻擊量`.
- Low-repair cards did not say how far price still was from the 5-day MA.

## User-Visible Result

- Trading-day 13:00-13:19 no longer falls through to `非交易`; it remains `盤中` until the `收盤` cutoff.
- Summary buckets now follow the visible card state: overheat names that already pulled back are counted as `等回測`.
- Overheat pullback triggers now say the concrete action:
  - normal pullback: `回測不破 + 量能不失控，再評估`.
  - sharp pullback: `守住回測支撐 + 非追高 + 量能不失控`.
- Rejected placeholder `觀察` is converted to `型態未過` when no better rejection reason exists.
- Breakout failure cards no longer display `攻擊量` / `趨勢量`; they display `放量回落` when applicable.
- Low-repair missing conditions show numeric gap, e.g. `站回5日均 161.2（差 2.45）`.
