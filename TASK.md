## Owner Problem

Owner reviewed the 06/23 intraday Telegram report from the mobile reader perspective and found visible strategy conflicts:

- Stocks that had already fallen sharply from overheated / breakout states still said `等冷卻`, which reads like the system is ignoring the pullback.
- Low-repair candidates repeated route text instead of clearly saying which concrete level still blocks a buy.
- Rejected cards could still show positive `修復中 / 權重 +1` history, creating a contradiction.
- The user needs every card to answer: what is happening now, what exact condition is missing, and when it can become actionable.

## User-Visible Result

- Overheated names that are still rising continue to show cooling / no-chase.
- Overheated names that have already pulled back now show:
  - `等回測｜回測確認` for normal pullback.
  - `等回測｜急殺回測` for sharp pullback.
- Low-repair cards now show compact actionable lines:
  - `觀察：近期支撐 X｜5日均 Y｜量能 Zx`
  - `還差：...`
  - `有效買點：守近期支撐 X + 站回5日均 Y + 量能不失控`
- `淘汰` cards no longer keep positive repair history lines unless the line is a true execution / failed-state memory.
